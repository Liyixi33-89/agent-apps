## 一、背景与目标

当前 Agency Agents Platform 的 Agent 列表页缺乏用户反馈机制，用户无法了解其他人对 Agent 的使用体验。增加评分评价功能可以帮助用户快速筛选优质 Agent，同时为 Agent 创建者提供改进方向。

**核心目标**：让用户能够对 Agent 进行评分和评价，并通过评分排序帮助其他用户发现优质 Agent。

---

## 二、需求清单

| # | 需求名称 | 优先级 | 简要描述 |
|---|---------|--------|---------|
| 1 | Agent 评分功能 | P0 | 用户使用 Agent 后可以打 1-5 星评分 |
| 2 | Agent 评价功能 | P0 | 用户可以为 Agent 撰写文字评价 |
| 3 | 评分评价展示 | P1 | Agent 详情页展示评分统计和评价列表 |
| 4 | 列表页评分排序 | P1 | Agent 列表页显示平均评分，支持按评分排序 |

> 优先级说明：P0=必须做 P1=应该做 P2=可以做

---

## 三、需求详情

### 需求 1：Agent 评分功能

**描述**：
用户在使用 Agent 进行对话后，可以对该 Agent 打 1-5 星评分。每个用户对同一个 Agent 只能评分一次，但可以修改已有评分。

**用户故事**：
作为 普通用户，我希望 在使用 Agent 后给它打分，以便 帮助其他用户了解 Agent 的质量。

**涉及角色**：普通用户

**初步验收标准**：
- [ ] 用户可以对 Agent 打 1-5 星评分
- [ ] 每个用户对同一 Agent 只能有一个评分
- [ ] 用户可以修改自己的评分
- [ ] 未登录用户不能评分

**原始表述**：
> 用户在使用 Agent 后可以给 Agent 打分（1-5 星）

---

### 需求 2：Agent 评价功能

**描述**：
用户在评分的同时可以撰写文字评价（可选）。评价内容限制在 500 字以内。用户可以编辑或删除自己的评价。

**用户故事**：
作为 普通用户，我希望 写下对 Agent 的使用感受，以便 帮助其他用户做出选择。

**涉及角色**：普通用户

**初步验收标准**：
- [ ] 用户可以撰写文字评价（可选，评分必填）
- [ ] 评价内容限制 500 字
- [ ] 用户可以编辑自己的评价
- [ ] 用户可以删除自己的评价

**原始表述**：
> 用户在使用 Agent 后可以给 Agent 打分（1-5 星）并写评价

---

### 需求 3：评分评价展示

**描述**：
Agent 详情页展示评分统计信息（平均分、评分人数、各星级分布）和评价列表（按时间倒序，支持分页）。

**用户故事**：
作为 普通用户，我希望 查看其他人对 Agent 的评分和评价，以便 决定是否使用该 Agent。

**涉及角色**：普通用户

**初步验收标准**：
- [ ] 详情页显示平均评分（保留一位小数）
- [ ] 详情页显示评分人数
- [ ] 详情页显示各星级的评分分布（如 5 星 60%、4 星 25%...）
- [ ] 详情页显示评价列表（按时间倒序）
- [ ] 评价列表支持分页（每页 10 条）

**原始表述**：
> 其他用户可以查看评分和评价列表

---

### 需求 4：列表页评分排序

**描述**：
Agent 列表页的每个 Agent 卡片上显示平均评分（星星图标 + 数字），列表支持按评分从高到低排序。

**用户故事**：
作为 普通用户，我希望 在 Agent 列表页看到评分并按评分排序，以便 快速找到高质量的 Agent。

**涉及角色**：普通用户

**初步验收标准**：
- [ ] Agent 卡片显示平均评分（星星 + 数字）
- [ ] 列表支持按评分排序（从高到低）
- [ ] 无评分的 Agent 排在最后

**原始表述**：
> Agent 列表页显示平均评分，支持按评分排序
