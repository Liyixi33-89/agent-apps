# PRD — Agent 收藏功能

**版本**：v1.3.0
**日期**：2026-04-14
**来源 BRD**：`version-doc/v1.3.0/brd/brd_normalized.md`

---

## 1. 概述

### 1.1 产品目标

为 Agency Agents 平台增加 Agent 收藏功能，让用户能快速标记和访问常用 Agent，提升使用效率和用户粘性。

### 1.2 成功指标

| 指标 | 目标值 | 衡量方式 |
|------|--------|---------|
| 收藏功能使用率 | ≥ 30% 活跃用户使用 | 统计收藏 API 调用量 |
| 收藏后复访率 | ≥ 50% | 收藏后 7 天内再次使用该 Agent |

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| 已登录用户 | 可执行收藏/取消收藏操作，查看个人收藏列表 |
| 未登录用户 | 可查看 Agent 收藏数，点击收藏时引导登录 |

---

## 2. 功能需求

### FR-001：收藏/取消收藏 Agent

**优先级**：P0
**角色**：已登录用户

#### 用户故事

作为已登录用户，我希望能在 Agent 卡片或详情页点击收藏按钮，将 Agent 加入我的收藏列表，以便下次快速找到。

#### 验收标准

- [ ] AC-001: Agent 卡片右上角显示收藏按钮（空心星标 ☆）
- [ ] AC-002: 点击空心星标 → 变为实心星标 ★，Agent 加入收藏列表
- [ ] AC-003: 点击实心星标 → 变为空心星标 ☆，Agent 从收藏列表移除
- [ ] AC-004: Agent 详情页同样显示收藏按钮，状态与卡片同步
- [ ] AC-005: 未登录用户点击收藏 → 弹出登录提示
- [ ] AC-006: 收藏/取消收藏操作响应时间 < 500ms
- [ ] AC-007: 收藏状态在页面刷新后保持

#### 交互细节

```
用户点击收藏按钮
├── 已登录
│   ├── 未收藏 → POST /api/favorites → 星标变实心 + 收藏数 +1
│   └── 已收藏 → DELETE /api/favorites/:agentId → 星标变空心 + 收藏数 -1
└── 未登录
    └── 弹出 Toast："请先登录后再收藏"
```

### FR-002：我的收藏列表

**优先级**：P0
**角色**：已登录用户

#### 用户故事

作为已登录用户，我希望在"我的 Agent"页面看到一个"收藏"Tab，展示我收藏的所有 Agent。

#### 验收标准

- [ ] AC-008: AgentsPage 新增"收藏"Tab（与现有"全部"Tab 并列）
- [ ] AC-009: 收藏 Tab 显示用户收藏的所有 Agent，按收藏时间倒序
- [ ] AC-010: 收藏列表中的 Agent 卡片样式与现有列表一致
- [ ] AC-011: 收藏列表中可直接取消收藏（点击星标）
- [ ] AC-012: 收藏列表为空时显示空状态引导
- [ ] AC-013: 收藏 Tab 上显示收藏数量角标（如"收藏 (5)"）

#### 交互细节

```
AgentsPage
├── Tab: 全部（现有）
├── Tab: 收藏 ({count})  ← 新增
│   ├── 有收藏 → 展示 Agent 卡片网格
│   └── 无收藏 → 空状态："还没有收藏的 Agent，去市场看看吧"
```

### FR-003：收藏数统计

**优先级**：P1
**角色**：所有用户

#### 用户故事

作为用户，我希望看到每个 Agent 被多少人收藏了，作为选择 Agent 的参考。

#### 验收标准

- [ ] AC-014: Agent 卡片显示收藏数（星标旁边）
- [ ] AC-015: Agent 详情页显示收藏数
- [ ] AC-016: 收藏数 < 1000 显示精确数字
- [ ] AC-017: 收藏数 ≥ 1000 显示简写（如 "1.2k"）
- [ ] AC-018: 收藏/取消收藏时收藏数实时更新

## 3. API 设计概要

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/api/favorites` | 收藏 Agent | ✅ |
| DELETE | `/api/favorites/:agentId` | 取消收藏 | ✅ |
| GET | `/api/favorites` | 获取我的收藏列表 | ✅ |
| GET | `/api/agents/:id/favorite-count` | 获取 Agent 收藏数 | ❌ |

---

## 4. 数据模型概要

### Favorite（新增）

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | ObjectId | 用户 ID |
| agentId | ObjectId | Agent ID |
| createdAt | Date | 收藏时间 |

**唯一约束**：`(userId, agentId)` 联合唯一

### Agent（扩展）

| 字段 | 类型 | 说明 |
|------|------|------|
| favoriteCount | Number | 收藏数（冗余字段，提升查询性能） |

---

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 收藏/取消收藏 < 500ms，列表加载 < 1s |
| 数据一致性 | favoriteCount 与实际收藏记录数一致 |
| 安全 | 收藏操作需认证，不能代替他人收藏 |
