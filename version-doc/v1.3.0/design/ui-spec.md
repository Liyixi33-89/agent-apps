## 1. 收藏按钮（FavoriteButton）

### 1.1 视觉规范

| 状态 | 图标 | 颜色 | 大小 |
|------|------|------|------|
| 未收藏 | `StarOutlined`（Ant Design） | `text-gray-400` | 20px |
| 已收藏 | `StarFilled`（Ant Design） | `text-yellow-400` | 20px |
| Hover（未收藏） | `StarOutlined` | `text-yellow-300` | 20px |
| Hover（已收藏） | `StarFilled` | `text-yellow-500` | 20px |
| Loading | `LoadingOutlined` | `text-gray-300` | 20px |

### 1.2 交互规范

- **点击区域**：图标 + 8px padding（最小点击区域 36x36px）
- **动画**：点击时 scale(1.2) → scale(1.0)，duration 200ms，ease-out
- **防抖**：连续点击间隔 < 300ms 时忽略后续点击
- **乐观更新**：点击后立即切换图标状态，API 失败时回滚

### 1.3 在 Agent 卡片中的位置

```
┌─────────────────────────────┐
│  🤖 Agent Name         ★ 42│  ← 右上角：收藏按钮 + 收藏数
│  Description text...        │
│  [Tag1] [Tag2]              │
│                    [使用 →] │
└─────────────────────────────┘
```

### 1.4 在 Agent 详情页的位置

```
┌─────────────────────────────────────┐
│  🤖 Agent Name                      │
│  Description...                      │
│                                      │
│  ★ 已收藏 (42)    [开始对话]        │  ← 收藏按钮 + 文字 + 收藏数
└─────────────────────────────────────┘
```

## 3. 收藏数格式化

| 数值范围 | 显示 | 示例 |
|---------|------|------|
| 0 | 不显示数字 | ☆ |
| 1 ~ 999 | 精确数字 | ★ 42 |
| 1000 ~ 9999 | x.xk | ★ 1.2k |
| 10000+ | xxk | ★ 15k |

## 4. 响应式适配

| 断点 | 收藏按钮 | 收藏数 |
|------|---------|--------|
| ≥ 768px | 图标 + 数字 | 显示 |
| < 768px | 仅图标 | 隐藏（详情页仍显示） |
