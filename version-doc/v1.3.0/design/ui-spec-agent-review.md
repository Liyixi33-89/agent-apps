# UI 设计规范：Agent 评分评价

> 版本：v1.3.0
> PRD 来源：version-doc/v1.3.0/prd/prd.md
> 生成日期：2026-04-14

## 一、设计概述

本文档定义 Agent 评分评价功能的 UI 设计规范，包括组件样式、交互状态、响应式布局。

---

## 三、组件规范

### 3.1 评分统计区域（ReviewStats）

```
┌──────────────────────────────────────────────┐
│  ┌─────────┐  ┌──────────────────────────┐   │
│  │  4.2    │  │ 5★ ████████████████ 50%  │   │
│  │ ★★★★☆  │  │ 4★ ██████████     25%    │   │
│  │ 56 人评价│  │ 3★ ██████        15%     │   │
│  └─────────┘  │ 2★ ██            5%      │   │
│               │ 1★ ██            5%      │   │
│               └──────────────────────────┘   │
└──────────────────────────────────────────────┘
```

**样式规范**：
- 容器：`p-6 bg-white rounded-lg border border-gray-100`
- 左侧平均分：`text-5xl font-bold text-gray-900`
- 左侧星星：Antd `Rate` size="default" disabled allowHalf
- 左侧人数：`text-sm text-gray-500 mt-1`
- 右侧分布：Antd `Progress` percent={百分比} showInfo size="small"
- 左右布局：`flex gap-8 items-start`

### 3.2 评价提交表单（ReviewForm）

```
┌──────────────────────────────────────────────┐
│ 你的评价                                      │
│ ★★★★☆  选择评分                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 写下你的使用感受...                        │ │
│ │                                          │ │
│ │                                 0/500    │ │
│ └──────────────────────────────────────────┘ │
│                              [提交评价]       │
└──────────────────────────────────────────────┘
```

**样式规范**：
- 容器：`p-6 bg-white rounded-lg border border-gray-100 mt-4`
- 标题：`text-lg font-semibold text-gray-900 mb-4`
- 星星：Antd `Rate` size="large"
- 文本框：Antd `Input.TextArea` rows={4} maxLength={500} showCount
- 按钮：Antd `Button` type="primary" size="middle"
- 未登录提示：`text-gray-500 text-center py-8`

**交互状态**：
| 状态 | 表现 |
|------|------|
| 默认 | 星星未选中，文本框空，按钮可点击 |
| 已有评价 | 星星预填，文本框预填，按钮文字变为"更新评价" |
| 提交中 | 按钮 loading，星星和文本框 disabled |
| 未登录 | 显示"请先登录后评价"，隐藏表单 |

### 3.3 评价列表（ReviewList）

```
┌──────────────────────────────────────────────┐
│ ┌──────────────────────────────────────────┐ │
│ │ 👤 user1    ★★★★★    2026-04-14         │ │
│ │ 非常好用的 Agent，回答准确！              │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ 👤 user2    ★★★★☆    2026-04-13         │ │
│ │ 整体不错，偶尔会有不准确的回答。          │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│              < 1  2  3  4  5 >               │
└──────────────────────────────────────────────┘
```

**样式规范**：
- 容器：`mt-4`
- 评价卡片：`p-4 bg-gray-50 rounded-lg mb-3`
- 用户名：`font-medium text-gray-900`
- 星星：Antd `Rate` size="small" disabled
- 时间：`text-sm text-gray-400`
- 评价内容：`mt-2 text-gray-700 text-sm`
- 分页器：Antd `Pagination` size="small" 居中
- 空状态：Antd `Empty` description="暂无评价，成为第一个评价者吧！"

### 3.4 Agent 卡片评分（AgentsPage）

```
┌─────────────────────────┐
│ 🤖 Agent Name           │
│ Agent description...    │
│                         │
│ ⭐ 4.2 (56)             │
└─────────────────────────┘
```

**样式规范**：
- 评分区域：`flex items-center gap-1 text-sm text-gray-500 mt-2`
- 星星图标：lucide-react `Star` className="w-4 h-4 text-yellow-400 fill-yellow-400"
- 评分数字：`font-medium text-gray-700`
- 评价数量：`text-gray-400`
- 无评分：`text-gray-400 text-xs` 显示"暂无评分"

## 四、响应式设计

| 断点 | 评分统计布局 | 评价列表 |
|------|------------|---------|
| ≥ 768px（md） | 左右并排 | 正常显示 |
| < 768px（sm） | 上下堆叠 | 正常显示 |

---

## 五、加载与空状态

| 场景 | 表现 |
|------|------|
| 评价数据加载中 | Antd Skeleton（3 行） |
| 无评价 | Antd Empty + 鼓励文案 |
| 加载失败 | Antd Result status="error" + 重试按钮 |
