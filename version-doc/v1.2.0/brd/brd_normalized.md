# BRD — Agent 收藏功能

**版本**：v1.2.0
**日期**：2026-04-14
**来源**：产品经理口头描述

---

## 1. 背景

当前 Agency Agents 平台上 Agent 数量持续增长，用户在使用过程中经常需要反复查找常用的 Agent。目前没有"收藏"机制，用户每次都需要从列表或市场中重新搜索，效率低下。

## 2. 目标

让用户能够快速标记和访问常用 Agent，提升使用效率。

## 3. 需求列表

### 需求 1：收藏 Agent

**优先级**：P0
**角色**：已登录用户
**描述**：用户可以在 Agent 卡片或详情页点击"收藏"按钮，将该 Agent 加入个人收藏列表。已收藏的 Agent 显示"已收藏"状态（实心星标），再次点击可取消收藏。

**原始表述**：
> 用户希望能收藏常用的 Agent，方便下次快速找到。

**业务规则**：
- 每个用户可收藏的 Agent 数量无上限
- 收藏操作需要登录，未登录用户点击收藏时提示登录
- 收藏/取消收藏为即时操作，无需确认弹窗

### 需求 2：我的收藏列表

**优先级**：P0
**角色**：已登录用户
**描述**：在"我的 Agent"页面（AgentsPage）增加"收藏"Tab，展示用户收藏的所有 Agent 列表，支持按收藏时间倒序排列。

**原始表述**：
> 需要一个地方能看到我收藏了哪些 Agent。

**业务规则**：
- 收藏列表按收藏时间倒序排列（最新收藏在前）
- 列表中的 Agent 卡片与现有 Agent 列表卡片样式一致
- 支持在收藏列表中直接取消收藏

### 需求 3：收藏数统计

**优先级**：P1
**角色**：所有用户
**描述**：在 Agent 卡片和详情页显示该 Agent 被收藏的总次数，作为热度参考。

**原始表述**：
> 如果能看到一个 Agent 被多少人收藏了就更好了。

**业务规则**：
- 收藏数为公开信息，所有用户可见
- 收藏数实时更新（取消收藏时减少）
- 显示格式：< 1000 显示精确数字，≥ 1000 显示 "1k+"、"2.5k+" 等

## 4. 术语表

| 术语 | 说明 |
|------|------|
| Agent | 平台上的 AI 助手角色 |
| 收藏 | 用户将 Agent 标记为常用，加入个人收藏列表 |
| Agent 卡片 | Agent 列表中展示 Agent 基本信息的 UI 组件 |

## 5. 非功能需求

- 收藏/取消收藏操作响应时间 < 500ms
- 收藏列表加载时间 < 1s
- 收藏数据需持久化存储

## 6. 排除范围

- 不包含收藏分组/文件夹功能
- 不包含收藏排序自定义
- 不包含收藏导入/导出
