# 全局执行规则 — 所有 Skill 必须遵守

## 强制完成规则

1. **绝不能在任务未完成时停止**。如果你感觉输出即将达到限制，先将已完成的部分写入文件，确保进度被持久化保存
2. **完成的定义**：所有源文件中提及的待处理项都已处理完毕，且自检/覆盖验证已执行
3. **自检/覆盖验证不可跳过**：Skill 中标注为"强制步骤"的步骤必须执行

## 断点恢复规则

1. **开始执行前，先检查是否有上次未完成的产出物**：
   - 如果目标目录下已存在同名输出文件 → 读取文件内容，分析哪些部分已完成，只补充缺失部分
   - 如果存在执行计划文档（`execution-plan-*.md`）→ 读取其中的任务状态，从 `⏳ 待执行` 或 `❌ 失败` 的任务继续
2. **每完成一个重要步骤后立即写入文件**，不要等全部完成再写

## 自主决策规则（异步执行场景）

当通过 CodeBuddy CLI 以 `-y` 模式后台运行时：
1. **遇到不确定的决策点，按最合理方案自行决策并继续**，将决策理由记录到输出中
2. **不要等待人工确认**——异步场景下没有人可以回答你的问题
3. 不确定的内容标注 `⚠️ 待确认` 但不要因此停止
